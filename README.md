# Ловим монетки

Автономный интерактив для сенсорного экрана 1920×1080. Для запуска в киоск-режиме откройте `start-fullscreen.bat`; для обычной проверки можно открыть `index.html`.

## Управление

- сенсор и мышь: нажатия, свайп по списку продуктов, ползунки;
- клавиатура на первом этапе: стрелки перемещают прицел, пробел ловит ближайшую монету;
- `Ctrl+D`: режим разработчика;
- параметр `?dev` в адресе: открыть режим разработчика сразу.

Режим разработчика позволяет менять заработанную сумму, отключать таймер, добавлять монеты и пропускать этапы.
